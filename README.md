# Second Dawn

Большой мод-переделка для Factorio 2.0 (без Space Age) по мотивам Dr. Stone: человечество окаменело,
игрок просыпается статуей и заново проходит путь от камня до ракеты на Луну, пока волны окаменения
приходят всё чаще.

Статус: проектирование, кода мода пока нет. Дизайн — [docs/DESIGN.md](docs/DESIGN.md).

## Инструменты
- `tools/balance_e1.py` — модель баланса эпохи 1: потоки, число машин, проверка дерева технологий на тупики.
  Запуск: `python3 tools/balance_e1.py`.
