# Style block for image prompts

Added to every Codex image task (docs/ART-HANDOFF.md), after the object description. Adapted from the
player's reference prompt (the Factorio-like crossbow, `art/reference/`): the same visual discipline, but
for all epochs — from stone age crafts to industry — and with restrained glow where the game needs it.

```
Goal: the object must look like one more existing asset of Factorio, not like concept art for another game. If "prettier" and "more like Factorio" disagree, choose Factorio.
Think function first, then construction, then material, then details: every large part is there for a reason; the object looks made and used by practical people in a harsh working world.
Epoch: <stone age craft | bronze and early metal | industrial>. Stone age and bronze objects are built by hand: lashings, wedges, pegs, tool marks, chips, patches — no bolts, plates or machined parts. Industrial objects may have bolts, plates, housings, hinges and pipes.
Materials: matte and semi-matte, worn, scratched, dirty in the crevices, naturally uneven. Wood with grain, dark patches and tool marks; stone rough and chipped; clay dusty with small cracks; leather and fiber frayed; steel cold dark grey; copper and bronze warm and dulled by oxidation. Nothing brand new, nothing glossy.
Colour: a muted palette — dark brown, grey-brown, steel grey, dirty beige, dark green, muted yellow, rust orange, near black. Bright colour only as a small functional accent. A glow, when the object has one, is soft and comes from a material inside, never magic runes or sparkles.
Form and light: chunky, heavy, readable forms, slightly exaggerated important parts, no perfect smooth shapes. Light from the top-left: bright top faces, darker sides, deep contact shadows where parts meet, modest highlights. Seen from above at an angle, like Factorio icons.
Readability: it will be shrunk to 32 pixels — silhouette first, large colour masses second, functional details third, fine details last.
Never: cartoon, cel shading, anime, pixel art, flat vector, glossy AAA concept art, fantasy RPG item art, decorative steampunk, neon, oversaturated colours, gold ornaments, magic effects, perfect symmetry, clean new surfaces, studio or cinematic light, photo, text, logo, UI, frame.
```
