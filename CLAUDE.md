# Second Dawn — как работать с проектом

Мод-переделка для Factorio 2.0 (base, без Space Age): пять эпох от камня до Луны, волны окаменения.
Что и почему — в `docs/DESIGN.md` (источник правды по механикам и числам), что видит игрок — в `README.md`.
Проект делается ИИ-агентами вместе с игроком (владелец репозитория, пишет по-русски).

## Правила игрока (обязательны)
- **Общение по-русски**, коротко. Код, комментарии, коммиты — по-английски.
- **Сначала дизайн, потом код.** Крупная механика — сначала предложение и вопросы, код — после согласия.
  Мелкие правки и исправления по отзыву из игры — сразу.
- **Игру игрока не трогать.** В `~/Library/Application Support/factorio/mods` кладётся только собранный zip,
  **только когда игрок скажет** и **только при закрытой игре**. Проверка: `ps -axo command= | grep "[M]acOS/factorio" | grep -v -- "--config /tmp/"`
  пусто — игра закрыта. Тестовые экземпляры (`--config /tmp/...`) не считать; `pgrep -f` не годится — он
  находит и оболочку, в чьей команде есть эта строка. Старый
  `second-dawn_*.zip` удалить, новый положить; `mod-list*.json` не трогать.
- **Коммитить только по просьбе.** Версию собирать (`build.sh`) тоже по просьбе.
- **Проверять самому**: безграфический экземпляр Factorio в отдельной папке (ниже). Сохранения игрока
  можно копировать в эту папку и грузить копию — это лучший способ воспроизвести его проблему.
- **Баланс в числах**: `tools/balance.py` — сколько машин и ресурсов на N в минуту, нет ли тупиков в дереве.
  Новые рецепты и технологии добавлять и туда.
- **Локализация**: русский и английский, всё сразу. Каждому предмету и зданию — описание (тест проверяет).
- **Факториопедия** должна быть честной: без ванильных дублей, всё своё на месте (тест проверяет).

## Устройство
- `data.lua` → `prototypes/` (эпохи, звери, климат, море, корабли, оружие, статуя, записки, мир);
  `data-final-fixes.lua` — скрыть ванилу, названия рецептов, иконки, Факториопедия, стоимость в описании
  технологий, графика из `prototypes/art.lua`.
- `control.lua` — одна точка входа: по одному обработчику на событие, общий цикл `on_nth_tick(30)`,
  миграции в `on_configuration_changed`, отладочный `remote`-интерфейс `second-dawn` (им пользуются тесты).
- `scripts/` — камера, статуи, волны, звери, ловля, климат, Луна, записки, дневник, подсказка, GUI.
- Всё состояние — в `storage`; случайность — только `game.create_random_generator` (мультиплеер).
- Префикс `sd-` у всего своего.

## Тесты
```bash
tests/run.sh                                        # синтаксис, локали, модель баланса — секунды
SD_TEST_DIR=/tmp/sd-test-x tests/run-scenario.sh <сценарий> <тики>
SD_TEST_DIR=/tmp/sd-test-all tests/run-all.sh       # всё, >10 минут — запускать в фоне
```
- Сценарии — `tests/scenarios/*.lua`, список и число тиков — в `tests/run-all.sh`. Новая механика —
  новый сценарий или проверка в существующем; баг из игры — сначала воспроизвести.
- **Разные прогоны — разные `SD_TEST_DIR`**, иначе они затирают друг другу мод и результаты.
- Долгие прогоны — в фоне, чтобы не блокировать разговор с игроком.
- Безграфический режим не грузит картинки и не показывает GUI: пути картинок проверяет
  `tests/check_files.py`, GUI — загрузка копии сохранения игрока (в нём есть подключённый игрок).

## Грабли, на которые уже наступали (Factorio 2.0)
- `--create` выходит с ненулевым кодом и при успехе: признак успеха — файл сохранения.
- Имя элемента GUI не может совпадать со свойством `LuaGuiElement` (`text`, `name`…).
- Добытое руками с деревьев и скал не попадает в статистику производства.
- У `LuaEntity` нет `spawner`; зверь, получивший команду скриптом, выходит из `lair.units`.
- Персонаж без игрока продолжает добывать — перед отключением игрока его останавливать.
- `unit_number` есть только у EntityWithOwner; `require` во время игры нельзя.
- Удалённые из прототипов предметы и технологии пропадают из сохранений — миграцию делать в коде.

## Графика
Отдельная сессия ведёт графику по `docs/ART-HANDOFF.md`: картинки из ChatGPT → `art/incoming/` →
`tools/art.sh <имя> <ширина в клетках>` → `prototypes/art.lua`. В основной сессии эти файлы не трогать
без нужды; перед сборкой убедиться, что графика доделана (тесты переводов и путей зелёные).

## Версии
`info.json` → `version`; игроку — `changelog.txt` (формат Factorio, англ.), история — `CHANGELOG.md` (рус.);
версии растут только последней цифрой (0.1.0 → 0.1.1 → 0.1.2), так решил игрок;
несобранные изменения копятся в `CHANGELOG.md` в разделе «Следующая версия». Сборка — `./build.sh`
→ `dist/2.0/second-dawn_<версия>.zip`.
